# Welcome to the Performant FS demo

This account comes with a few sample files. Try typing these in the search box:

- `quartrly` → a typo still finds "quarterly"
- `halting` → a word that only appears *inside* a PDF (Coursework)
- `halting type:pdf in:Coursework` → the same, with filters
- `how do plants make food` → found **by meaning**: no file contains those words
- `weekend getaway to Portugal` → also by meaning (Travel)
- `football world cup results` → nothing is related, and it says so

Then upload your own files: drag a whole folder onto the page, or a large video
(it goes up in resumable 8 MB pieces; turn your network off and on mid-upload).
